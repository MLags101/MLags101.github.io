## Overview

STM Remote continues my push into embedded systems: designing and programming custom PCBs around the **STM32** family. It evolves my earlier Custom Remote — where that board was a simple trigger, this one adds an accelerometer/gyro module and a larger button array for intuitive robot control.

## Design philosophy

With the IMU, the user directs motion by moving the hand holding the remote. That makes control far more intuitive, especially for people new to driving robots.

<Figure src="stm-rem-sch.png" alt="Full schematic of the STM Remote" caption="STM Remote schematic." contain />

## Technical challenges

I learned STM32 hardware design from Phil's Lab on YouTube and ST's datasheets. It was harder than expected — from the precise external **crystal oscillator** circuit to the large **decoupling capacitor network** needed for clean power. Using a board house raised the stakes: every mistake meant weeks of waiting for revised boards, so reviews had to be meticulous.
