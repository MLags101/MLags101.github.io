QuadFrog

About

This project is my hands-on exploration of drones and their capabilites. I wanted to grow my skills in many different areas by developing as many components of the drone myself. As such, I designed and fabricated the frame of the drone, choosing a V-tail configuration to account for the position of my battery. I selected and soldered the main drone electronics, as well as built my own ground station module compatible with my laptop. Finally, I wrote Python and C++ programs to run on the on-board Raspberry Pi flight computer as well as ground control programs for my laptop and accompanying GCS hardware. I was glad to apply experience from my previous VIP as well as lessons from classes such as Statics. I was able to grow several skills as well as learn a few more over the course of this project, and the drone itself will serve as a test-bed for any flying project I want to develop.

This project was a self-driven exploration into drone design, aimed at developing a custom quadcopter from the ground up to expand my skills in mechanical design, electronics, and programming. I designed and fabricated a V-tail frame, soldered the main drone electronics, built a compatible ground station module for laptop control, and wrote Python and C++ programs for both the onboard Raspberry Pi flight computer and ground control system (GCS). Drawing on experience from my Vertically Integrated Project (VIP) and coursework like Statics, I created a versatile drone to serve as a testbed for future flight experiments.
My passion for drones stems from their blend of mechanical, electrical, and software engineering, offering endless possibilities for innovation. This project was an opportunity to challenge myself by designing and building as many components as possible, fostering a deep understanding of drone systems. My goal was to create a functional, customizable platform that not only flies but also serves as a foundation for future experimentation, reflecting my commitment to hands-on learning and interdisciplinary engineering.
The project began with defining the drone's V-tail configuration, chosen to increase forward flight capabilities and optimize component placement. I used Fusion 360 to design the frame, ensuring structural integrity(after a few interations and lessons learned) and precise motor placement for balanced flight.

The onboard flight computer, a Raspberry Pi, ran custom Python scripts to manage flight control inputs and sensor data, interfaced with the flight controller via a serial connection. For the ground station, I built a custom box using an Raspberry Pi Pico and HC-12 radio module, paired with Python GCS software I wrote on my laptop for real-time control and telemetry.
Over the course of my iterations, I improved many features as I tested and researched more about drone building. I improved the arm design by moving from a flat arm to a more I beam shaped design to account for the weakness of PLA. I incorporated a live digital camera feed using a webcam connected to the onboard Raspberry Pi, which streamed over a self hosted python flask server. Unfortunately, some of these changes increased the amount of wiring and slack that had to be tied up or taped down, which wasn't visually pleasing.

For fabrication, I 3D-printed the frame using the Ultimakers at the Invention Studio with PLA filament, iterating on prototypes to address issues like frame cracking and arm bowing. The final frame was lightweight yet robust, supporting the drone's electronics. I selected and soldered components, including a flight controller, ESCs, and motors onto an off the shelf power-distribution board. An issue I faced was working with powerful electronics like LiPo batteries for the first time, and because I didn't realize how dangerous they were and because of how new I was to these components, I ended up accidentally blowing up an ESC in my dorm, nearly setting off the fire alarm. It was very stressful, but I'm partially glad it happened because it quickly taught me to respect the hardware and to be more careful with my procedures, which is why I now always double-check through continuity testing with a multimeter.

This project merged mechanical design, electronics, and programming. The V-tail frame's sleek aesthetic was both functional and visually appealing, inspired by a favorite game of mine: Watch Dogs 2. Mechanically, I applied Statics to ensure structural stability. Electronically, I gained important experience with soldering and UAV part selection. In software, I integrated Python with the Pixhawk to create a cohesive control system. This fusion of disciplines produced a drone that I'm proud of as an early technical achievement in my work with UAVs as well as a practical basis for future projects.
