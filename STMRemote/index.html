STM Remote

About

As a continuation of my pursuit to learn embedded systems, I started this project to learn how to design and program custom PCBs using the STM32 family of microcontroller chips. The more practical purpose of the project is to be an evolution of my previous remote project, but where that remote acted as simply a trigger for arbitrary devices, this remote will include an accelerometer/gyro module and a larger array of buttons so that the user can utilize the remote to control robotic(or airborne) movement. Using the IMU(inertial measurment unit), which is the accelerometer/gyro module, the user can direct motion using the motion of the hand holding the remote, enabling much more intuitive and easy control, especially for people newer to controlling robots.

I leveraged online resources to learn how to design with these chips, specifically Phil's Lab on YouTube, and of course the very extensive datasheets provided by STMicroelectronics. The process was more difficult than I expected due to the specificity needed when tailoring circuits to a specific STM chip from the precise external crystal oscillator circuit, to the large capacitor network highly suggested in the datasheets to ensure proper power delivery. If I got something wrong and ordered the circuit, I would have to wait weeks to receive it, find the issue, fix it in the design, and wait many more weeks to get the updated version. When using a Fab house, I knew that I had to be meticulous in my design process in order to ensure I use my time effectively.
I'm currently in the process of assembling and testing the received boards.
